# CloseMeansExit 0.2.3-beta.1 · Beta 测试版

目前仅实现基本功能，真实应用兼容性仍需逐项验证。觉得好用，别忘了 Star ⭐！

## 延迟关闭修复

此前，部分应用点叉后三秒仍显示窗口时，工具会丢弃此次关闭操作。窗口稍后才隐藏，即使已经在黑名单中，也只能留下“疑似后台驻留”记录。

现在会保留被点窗口的句柄和实际所属进程身份。仅当整个应用进程树中唯一可见窗口就是该原窗口、身份吻合、未最小化且未禁用时，继续观察其关闭过程。总有效期仍从原输入时间起计算，最长十秒；完全隐藏后仍需稳定一秒。窗口重新出现、规则更改、暂停或身份无法确认时取消。

其他窗口、最小化窗口、保存提示和子进程窗口仍受保护。终止前仍会再次核验整个进程树的窗口与身份。单纯“窗口消失”不会授权结束进程。

## 使用

从托盘退出旧版后运行新版。现有黑名单和兼容选项保存在本机，不因切换版本而重置。

Steam 主规则对应 `Steam.exe`。如果希望同时结束 WebHelper，需要由使用者明确启用“包含子进程”；该选项也可能包含由 Steam 启动的游戏，不应仅为清理 WebHelper 而默认开启。

## 验证范围

新增慢关闭、原窗口身份、保护窗口、规则变化和十秒上限的回归检查。专用夹具用程序注入关闭信号，延迟 4.5 秒隐藏窗口，再通过真实协调器核验结果；此检查不代表真实 Steam 的实体鼠标关闭已经通过验收。

本机 Windows x64 编译零警告、零错误，258 条核心断言及完整原生检查通过，4.5 秒延迟隐藏的专用夹具在真实协调器中正确结束。原窗口最小化、第二窗口、保存对话框和伪造实际所属进程身份均不能取得延长等待条件。

ARM64 实机和真实应用兼容性仍需分别确认。
