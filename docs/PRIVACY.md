# 隐私与发布内容说明

项目提供源码、测试、构建及 Beta 标签发布配置。公开构建和发布记录以对应 GitHub 仓库的 Actions、Releases 页面为准。

0.2.2-beta.1 的右下角提醒卡片在本机显示程序 `.exe` 名字、完整安装路径和进程工作集。待处理提醒保存在内存队列；选择“暂不处理”不会写入黑名单，主动选择“加入黑名单”成功后才保存该路径及规则。

## 源码包范围

源码发布包仅包含项目代码、测试代码、项目文件、说明、许可证和 CI 配置，不包含：

- `.git` 目录、提交历史、远程地址或本机 Git 配置。
- `bin/`、`obj/` 等本机构建输出及中间文件。
- 用户运行时的 `settings.json`、损坏配置备份、活动日志及日志轮换文件。
- 登录凭据、访问令牌、账户信息或本机绝对路径。

源码中测试用的 `C:\Apps\...` 等 Windows 示例路径是虚构夹具，不是用户真实安装目录。文档中的 `%LOCALAPPDATA%` 为通用 Windows 环境变量，`OWNER` 为未来目标仓库的占位符。

## 运行时数据

应用运行后会在当前用户的 `%LOCALAPPDATA%\CloseMeansExit` 保存本机数据：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 主动添加的应用完整路径、规则选项和开机启动选择 |
| `settings.json.broken-*` | 配置读取失败时保留的原配置副本 |
| `activity.log`、`activity.log.previous` | 应用名字和事件等运行记录，不保存窗口标题 |

这些文件仅保存在本机，应用不上传应用列表、窗口标题或遥测。完整安装路径属于本机配置内容，请不要把配置、备份和日志提交到源码仓库。

`--notification-demo` 仅使用合成示例展示提醒卡片，不检测或结束真实进程，不保存任何设置。演示路径与工作集不是当前电脑应用的实际数据。

`.gitignore` 已排除 `settings.json`、`*.broken-*`、`*.log` 和 `activity.log.previous`，用于防止这些文件被误收。忽略规则不会自动移除已经提交过的文件；手动维护仓库时，应保留这个边界。

## 后续发布

随附的 GitHub Actions 定义源码测试、Windows 构建及 `v*` 标签的 Beta 预发布流程。推送源码或版本标签后触发对应工作流；仓库不包含个人账户连接信息或凭据。
