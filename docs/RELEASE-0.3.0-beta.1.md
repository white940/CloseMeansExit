## 黑名单自动清理后台实例

加入并启用黑名单后，工具会定期检查该完整程序路径的运行实例。只要应用及其子进程没有可见窗口，经过短暂等待和身份复核，就自动结束该实例，不再要求先识别点叉或 Alt+F4。

- 加入规则时已经在后台的实例也会自动处理。
- 启动工具、恢复监测或重新启用规则时，已有后台实例会重新检查。
- 未加入或已停用的规则不会授权自动结束；发现未列入的驻留应用仍可提醒。
- 最小化窗口、其他可见窗口及保存提示继续保护应用。窗口重新出现会取消正在等待的操作。
- 暂停、删除规则、修改结束范围或身份核验失败会取消当前操作。
- 按完整路径匹配，结束前再次检查 PID、创建时间、路径和窗口，禁止只按进程名批量结束。

## 升级须知

**旧版本保存的已启用规则也采用新行为。** 保存后无需再关闭一次窗口，自绘关闭兼容也不再是自动处理的前提。后台下载、同步等任务也可能被结束；需要保留时请暂停监测或停用该规则。

子进程范围依然由每条规则明确选择。Steam 请选择主程序 `Steam.exe`；只结束主程序时不要另行启用 `steamwebhelper.exe` 的自动处理规则。“包含子进程”可能包括由 Steam 启动的游戏。

本机 Windows x64 已通过 293 条核心断言和完整原生、通知及后台扫描集成检查，编译零警告、零错误。后台链路检查不注入点叉信号，覆盖加入后立即纳入当前后台实例、启动前已隐藏、暂停恢复、规则删除与启用，以及同路径可见/最小化实例保护。

Windows x64 和 ARM64 便携包由对应标签的 GitHub Actions 构建；ARM64 构建不代表实机验收。自动回归使用专用可丢弃夹具，真实应用兼容性仍需逐项验证。
