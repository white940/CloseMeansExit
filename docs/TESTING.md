# 验证与人工验收

当前版本采用“启用黑名单后自动处理后台实例”，旧版本说明中的“下一次点叉才生效”不再适用。

## 自动检查

```powershell
dotnet run --project tests/CloseMeansExit.Tests -c Release
dotnet build src/CloseMeansExit.Windows -c Release
dotnet run --project src/CloseMeansExit.Windows -c Release --no-build -- --smoke-test
```

核心检查使用模拟时间和进程快照；Windows 检查使用独立启动、可丢弃的测试夹具。测试不得按进程名结束真实应用。原生测试覆盖路径、启动时间、窗口、最小化、保存提示、父子关系和结束范围。

后台自动处理链路必须验证真实轮询、实际规则变更和终止结果，不能仅通过注入点叉信号宣称通过。

## 行为矩阵

| 场景 | 预期 |
| --- | --- |
| 未列入规则的应用隐藏后仍运行 | 只发现和提醒，不自动结束 |
| 提醒中加入黑名单，应用仍在后台 | 当前实例经过等待后自动结束，无需再次点叉 |
| 停用的规则重新启用，实例已在后台 | 重新检查并自动处理 |
| 启动工具前已隐藏的黑名单实例 | 即使从未观察到该窗口，也能发现并处理 |
| 应用仍可见或最小化 | 保留进程 |
| 主窗口关闭但还有第二窗口、子进程窗口或保存提示 | 保留进程 |
| 后台等待期间窗口重新出现 | 取消本轮；重新隐藏后从新检查开始等待 |
| 等待期间暂停、删除或停用规则 | 取消本轮，不继续执行 |
| 恢复监测 | 重新检查后台实例，不沿用旧的待执行请求 |
| 等待期间改动包含子进程选项 | 取消旧范围，重新核验新规则 |
| 同名但完整路径不同的程序 | 不匹配该规则 |
| PID 被复用、创建时间或路径不同、访问/枚举失败 | 取消操作 |
| 应用自然退出 | 不操作替代实例 |
| 子进程范围关闭 | 只结束规则匹配的主实例，仍保护子进程的窗口 |
| 子进程范围开启 | 只处理核验通过的本次进程树，排除无关同名进程 |
| 通知保存失败 | 显示错误并允许重试，规则未保存时不授权执行 |

## 人工验收

先选择没有未保存工作或后台任务的测试应用，记录程序版本、规则路径、是否包含子进程、Windows 架构及时间。分别测试加入时已隐藏、重新启动监测、最小化、多窗口、保存提示、暂停恢复和规则禁用。

Steam 使用 `Steam.exe` 主规则；验证只结束主程序时应停用独立的 WebHelper 规则。包含子进程可能影响由 Steam 启动的游戏，需单独验收。自动夹具检查不代表真实 Steam 或其他应用已通过验收。

完整解压发布 ZIP 后再启动；切换前退出旧工具。ARM64 产物需要 ARM64 实机验证，构建成功不能替代实机结果。日志位于 `%LOCALAPPDATA%\CloseMeansExit\activity.log`，请勿把个人配置和日志提交到公开仓库。
