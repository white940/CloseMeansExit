# CloseMeansExit 0.2.2 验证记录

日期：2026-10-31。Windows 11 x64，.NET SDK 10.0.403。

## Steam 实机只读证据

用户配置仅包含 steamwebhelper.exe，未启用自绘兼容；日志只记录窗口消失，没有确认关闭动作。实际 Steam 主窗属于 CEF helper，主程序是同一安装目录的 Steam.exe。

对隐藏 SDL 窗口右上关闭区域进行只读命中采样，得到客户区或标题栏结果，没有标准 HTCLOSE；隐藏状态采样不能代替实际点击验收。Steam 主程序 Probe 可靠、当前没有可见后代窗口。

新解析器已对正在运行的真实 Steam 作只读验证：窗口 helper 被解析到它在同一安装目录的真实 Steam.exe 祖先，身份及窗口核验可靠。未点击、关闭或结束真实 Steam，未修改用户的黑名单配置。

## 范围与待测项

人工初步反馈：2026-10-31，0.2.2 使用者反馈“感觉可以了”。此处仅记录初步使用体验，不据此认定全部真实输入、游戏、下载及窗口布局场景均已通过验收。

真实 Steam 的实体鼠标点叉、Alt+F4，以及包含游戏、下载和多种 UI 布局时的完整流程仍待人工验收。完整流程测试的强关闭信号通过协调器注入，不能称为真实 Steam 点叉实测通过。

现有 helper 规则不自动迁移。新卡片需确认 Steam.exe 路径；自绘兼容和子进程执行范围均由用户明确选择。系统程序、其他窗口及旧点击不能因迁移或新设置获得额外结束权限。
